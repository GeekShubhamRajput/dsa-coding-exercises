# Data Structures & Algorithms

A collection of **Data Structures and Algorithms (DSA) coding exercises** implemented in **Python and Ruby**.

The goal of this repository is to practice problem-solving, understand core data structures and algorithms, and improve coding skills through hands-on exercises.

## 🛠 Languages

* 🐍 Python
* 💎 Ruby

### Data Structures

* Linked List
* Doubly Linked Lists
* Stacks and Queues
* Trees
* Binary Search Tree(BST)
* Hash Tables
* Graphs
* Heaps

### Algorithms

* Searching
* Sorting
* Recursion
* Two Pointers
* Sliding Window
* Binary Search
* Tree Traversal
* Graph Traversal
* Dynamic Programming
